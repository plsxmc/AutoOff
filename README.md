# 定时关闭管家 AutoOff

Windows 本地绿色小工具：**定时关闭指定游戏/程序 · 定时关机等电源操作**。

- 绿色免安装，单文件运行，纯本地工作，不上传任何数据
- 支持定时关闭指定进程（内置梦幻西游端游 my.exe / 手游桌面版 mymain.exe 预设）
- 支持"点选窗口"定向关闭：像录屏软件选窗口一样，屏幕上点哪个窗口就关哪个，不依赖进程名
- 支持倒计时 / 每天 / 每周 / 指定日期时间四种调度，执行前弹窗提醒、可取消
- 支持关机 / 重启 / 睡眠 / 休眠 / 锁屏 / 注销

## 快速上手

1. 双击运行，程序驻留系统托盘；
2. **定时关闭游戏**：点「新建任务」→ 选"关闭指定进程/游戏" → 点「插入游戏预设」选梦幻西游（或「从运行中进程选择」）→ 选时间 → 保存；
3. **点选窗口定向关闭**：点「新建（点选窗口）」→ 屏幕变暗，单击要关闭的窗口（可切「显示全部窗口」模式，进程名不对也能选）→ 设定启用后多少分钟执行 → 创建；
4. **定时关机**：点「新建任务」→ 选"关机" → 选时间 → 保存；
5. 触发前会弹出倒计时提醒，可「取消本次执行」或「立即执行」。

## 常见问题

- **游戏关不掉 / 提示部分成功**：游戏以管理员权限运行时，请以管理员身份重启本工具（设置页或点选失败提示中有一键提权）。
- **杀毒软件误报**：程序由 PyInstaller 打包，个别杀软可能误报；本工具不联网、不修改任何游戏文件，可加入信任列表。
- **多开区分账号**：用「新建（点选窗口）」点选摆摊/目标号对应的窗口，只会关闭该实例，不影响其他号。
- **日志**：`data\logs\` 按天分文件，单文件超 5MB 自动分卷，默认保留 30 天自动清理（可在 `data\config.json` 调整 `log_keep_days`）。

## 合规说明

本工具为**个人本机时间管理辅助**：仅按时间触发关闭本机进程或执行电源操作，不联网、不读写游戏内存、不注入、不代为操作游戏，不绕过任何游戏防沉迷/反作弊机制。
